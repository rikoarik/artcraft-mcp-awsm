# Worked decision records: design foundations and repair

These are examples of reasoning outputs, not pre-approved palettes/font pairings
or claims about research performed for a new task. Inspect actual references and
assets before adopting a choice. Keep the final explanation short.

## Operations console

Observation: the supplied current screen has five competing card headers while
the invoice queue is below the fold. Operator task: find work requiring attention.
Recommendation: expose the queue and a compact context toolbar; retain the brand
accent and existing licensed sans. Use tabular figures for amounts, separate
surface/border/text roles and text-bearing statuses. Reject animated particle
backgrounds because they compete with comparison and input. Evidence needed:
main queue visible, filters retained, keyboard focus and actual amount alignment.

This is not 'all admin must be gray'. If a brand calls for warm/cool color fields,
use them in shell/context regions and test contrast and density in the work area.

## Expressive product website

Observation to look for: a supplied reference separates foreground subject,
background world and stable copy, rather than treating a product image as a card.
Recommendation: one coherent material/environment, actual product art, differentiated
section compositions and a deliberate transition into detail. Type should express
the brand while body copy remains readable. Reject unrelated stock landscapes and
pasted gallery effects. Evidence: actual subject crop and copy remain legible across
opening, transition and mobile states. If the reference could not be viewed, say so.

## Asset decision matrix

| Need | First choice | Alternative / limits |
| --- | --- | --- |
| Actual product proof | Authorized real UI/product image | Labeled illustration if real proof is unavailable |
| Familiar navigation/action | Existing coherent licensed icon family | Original vector only for a missing concept |
| Specific human/place/subject | Relevant licensed photography | Authorized image-generation tool; inspect output |
| Simple diagram/social graphic | Original SVG/layout | make_asset is a limited template, not a photo model |
| Object turn/exploded view | Supported native model/render | Pre-rendered image/sequence if interaction adds little |
| Material/atmosphere | Purposeful texture/image/layered composition | A plain surface when it improves the actual task |

For fonts, start from existing license/coverage and test headline shape, dense
labels, amounts and long copy. Select one family or a justified display/body pair;
show real samples locally rather than asking the user to choose from a catalog.
For icons inspect optical weight at actual size. For photos inspect focus/crop,
lighting, negative space and provenance. For generated art retain the source/tool
and do not present fictional product screens or results as authentic evidence.

## Anti-slop repair record

Before: identical rounded cards with vague titles, decorative counters and a hero
that could describe any product. Cause: content hierarchy and evidence are absent.
Change: replace titles with actual tasks/benefits, choose a meaningful dominant
visual, vary composition by content and remove unsupported counters. Preserve
working navigation, brand and accessibility. After: compare the same viewport/state
and name which concrete task is clearer. Do not claim a win from a font/color swap.
