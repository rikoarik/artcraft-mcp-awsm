# Design system ringan

1. Inventarisasi brand dan komponen saat ini; hindari membuat sistem baru untuk satu landing page kecil.
2. Bentuk token primitive (warna, spacing, type), semantic (surface, text, border, accent, danger), lalu component tokens bila perlu.
3. Dokumentasikan state komponen: default, hover, focus, disabled, loading, error, dark mode jika ada.
4. Uji kontras, panjang teks, responsiveness, dan skala 200%. Token tidak menggantikan pengujian UI nyata.
5. Simpan keputusan dan contoh penggunaan di repo; beri nama berdasarkan peran, bukan warna literal untuk semantic tokens.
