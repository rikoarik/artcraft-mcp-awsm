# UI/UX best practices

1. Tentukan tugas utama user dan jalur tercepat menyelesaikannya. Kurangi pilihan sebelum menambah komponen.
2. Gunakan semantik HTML, heading berurutan, label form eksplisit, error spesifik yang bisa ditindak, status loading/empty/success.
3. Pastikan seluruh kontrol dapat dioperasikan keyboard, fokus terlihat, urutan fokus masuk akal; jangan bergantung pada hover.
4. Uji kontras teks dan state, ukuran target sentuh yang nyaman, zoom 200%, teks panjang dan lokalisasi.
5. Untuk mobile, prioritaskan konten dan interaksi; cek overflow, sticky element, menu, dan keyboard virtual.
6. Tanyakan apakah animasi membantu orientasi; dukung reduced motion. Jangan sembunyikan konten penting ketika script gagal.
7. Verifikasi di browser pada beberapa viewport dan laporkan temuan dengan severity, bukti, dan saran perbaikan.
