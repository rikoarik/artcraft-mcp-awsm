# CAD-only deliverable

Inspect the intended drawing through its native attached session. Read units,
entities, layers, dimensions and annotations before interpreting shape. Model only
the requested 2D changes with actual provider commands; do not infer wall heights
or manufacture a 3D building from unmeasured screenshot pixels.

Use staged edits and native undo/rollback where supported. Verify dimensions,
closed/open profiles, layer placement and a rendered drawing. Preserve the user's
existing/unsaved work and save only to the authorized destination. Provide the
native drawing and inspection evidence, not an unrelated website package.

A CAD request is complete with the requested 2D drawing. Only a request to convert
it into 3D selects SolidCraft as a second provider. In that case the source plan
remains authoritative for measured geometry; unknown heights/openings require
explicit treatment. Native modeling does not itself request website publishing.
