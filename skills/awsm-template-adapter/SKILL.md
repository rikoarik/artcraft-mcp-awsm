# Template adapter

1. Cari template yang tersedia di repository/proyek; periksa README dan lisensi sebelum memakai template dari luar. Jangan mendownload template acak tanpa konfirmasi.
2. Petakan bagian template ke brief: konten, layout, komponen, assets, fonts, breakpoints. Catat bagian yang dipakai atau diganti.
3. Pertahankan struktur dan dependency project bila masuk akal; ganti konten placeholder dengan copy spesifik, sumber gambar berlisensi, dan state yang berfungsi.
4. Periksa seluruh link, CTA, form, responsivitas, dan aksesibilitas. Jangan mengklaim desain orisinal jika template pihak lain menjadi basis.
5. Simpan atribusi dan syarat lisensi; jika izin tidak jelas, buat layout baru yang terinspirasi prinsip umum, bukan menyalin source.
